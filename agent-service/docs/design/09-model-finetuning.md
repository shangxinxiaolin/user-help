# 模型微调

> 用飞轮攒下的万级问题训一台主题分类器，批量归类"用户最常卡在哪一类"，排出补知识优先级。

## 背景与问题

低置信度问题池攒了几千上万条，要按固定主题类目批量归类，看哪类堆得最多、最缺知识。量大（万级）+ 类目固定 + 要便宜要快——提示词逐条打标压不住这个规模。

## 设计

- **何时微调**：三道坎（few-shot 举不完 / 方言口语错别字易错 / 海量逐条调大模型贵慢）+ 算账（量大 + 类目稳才回本）。
- **任务**：多标签文本分类，字面提到几个主题标几个。
- **选型**：编码器 RoBERTa-wwm-ext（约 1 亿参数）全参微调，消费级显卡可跑。
- **数据四步**：清洗脱敏 → 归并术语表（单一份）→ 分层抽样划分（8:1:1）→ 数据增强（只扩训练集）。
- **标注**：大模型照术语表预标 + 人工抽样把关。
- **验证**：精确率 / 召回率 / F1 / 混淆矩阵 + 容错红线 + 自建评测集。
- **部署**：旁路批量跑，ONNX 导出到推理服务。

## 选型理由

- **意图识别（多轮）不微调、主题归类（单句）微调**：意图识别是会话维度（对话状态追踪，读整段历史）走大模型；主题归类是单句维度（上游指代消解 + 标准化已去上下文），正好落小模型舒适区。
- **分类用编码器、不用生成式大模型**：BERT/RoBERTa 整句压向量、每类独立出分，天生为分类长；生成式做分类是"模拟"。
- **全参微调就够**：一亿参数几个 G 显存能训，PEFT/LoRA/QLoRA 留到几十亿参数模型再启用。

## 关键结论与坑

- **数据质量排第一**：效果不行先搞数据（补稀缺类目、修 label noise、正则化 + 早停），排在模型大小和训练技巧前面。
- **归并术语表只有一份**：全系统对齐，术语表乱则标签乱。
- **数据增强只扩训练集**：验证/测试保持原样，防"考前漏题"。
- **Embedding 微调是最后手段**：先做切分、混合检索、重排，都到位还差一口气才动。
